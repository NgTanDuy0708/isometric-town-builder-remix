# Prompt tạo công trình — đồng bộ Forest Pack

Cách dùng mỗi lần:
1. Dán **SYSTEM INSTRUCTION** trong [ART_STYLE_FOREST_PACK.md](ART_STYLE_FOREST_PACK.md) làm system/style prompt.
2. Dán 1 prompt công trình bên dưới.
3. Dán negative prompt ở cuối.
4. Xuất PNG 1024×1024, nền trong suốt.

---

## Negative prompt (dùng chung)

```text
photorealistic, 3D render, smooth shading, soft gradients, anti-aliased edges,
blurry, glow, depth of field, ground tile, grass base, dirt patch, cast shadow,
multiple buildings, people, animals, text, watermark, logo, border, frame,
perspective distortion, fisheye
```

## Mẹo để ra đúng pixel
- Thêm vào cuối prompt: `32x32 pixel art readability, 4x nearest upscale`.
- Nếu model ra nét mảnh: thêm `thick 1-pixel outline, chunky pixel clusters`.
- Nếu ra màu lệch: thêm `use only palette #1e4615 #32571d #6d8740 #8a3c24 #ba9745 #709fcf #c9c8bd`.
- Mỗi lần chỉ 1 công trình, không đặt cạnh công trình khác.
