# Prompt nâng cấp công trình (Lv.1 → Lv.3)

Danh sách lấy từ `UPGRADES_CONFIG` — mọi công trình có nâng cấp, **trừ Kho Tổng Hợp**.
Mỗi prompt dùng kèm **SYSTEM INSTRUCTION** trong [ART_STYLE_FOREST_PACK.md](ART_STYLE_FOREST_PACK.md) và negative prompt trong [BUILDING_PROMPTS.md](BUILDING_PROMPTS.md).

Quy ước: mỗi cấp là **một ảnh riêng**, cùng footprint, chỉ đổi độ hoành tráng.
Style tail dùng chung:

```text
Strict 2:1 isometric, 4px pixel blocks, 1-pixel dark outline, light from
top-left, Forest Pack palette only, transparent background, no ground,
no shadow, no text.
```
